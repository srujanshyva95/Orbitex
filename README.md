# Orbitex

A clean, dark-mode personal planner dashboard built with Next.js, Tailwind CSS, Framer Motion, Lucide icons, and browser localStorage.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Current MVP

- Dashboard cards
- Task manager
- Priority and due dates
- Upcoming meetings section
- Quick notes / brain dump
- Carry-forward button for overdue unfinished tasks

## Next Step

Add optional cloud sync after the localStorage MVP is stable.
